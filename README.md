# YouTube — Не интересует для Firefox

Отметьте несколько видео на главной странице YouTube и нажмите одну кнопку «Не интересует». Расширение последовательно открывает меню выбранных роликов и нажимает соответствующий пункт.

## Статус

Прототип, версия 0.1.3. Новое расположение флажков на живой странице YouTube в Firefox пока не проверено. Разметка YouTube может различаться между аккаунтами и изменяться со временем.

Счётчик «Нажатий» показывает выполненные клики, а не подтверждение сохранения обратной связи сервером YouTube.

## Возможности

- Выбор обычных видео только на главной странице `https://www.youtube.com/`.
- Флажок в левом верхнем углу превью, без отдельной строки над видео.
- Панель появляется после выбора видео, остаётся на время обработки и скрывается, когда обработка завершена и выбор пуст.
- Общая кнопка «Не интересует» и последовательная обработка выбранных роликов.
- Снятие выбора и остановка обработки. Остановка не отменяет уже выполненные действия.
- Сброс выбора при переходе на другую страницу YouTube.
- Поддержка пунктов меню «Не интересует» и `Not interested`.
- Shorts и отдельные тематические секции не обрабатываются.

## Временное подключение

1. Скачайте исходники репозитория через **Code → Download ZIP** и распакуйте архив. При наличии локальной копии используйте её.
2. Откройте в Firefox `about:debugging#/runtime/this-firefox`.
3. Нажмите кнопку загрузки временного дополнения. В английской документации Mozilla она называется **Load Temporary Add-on…**; название в вашей русской версии Firefox может отличаться.
4. Выберите файл `manifest.json` из папки расширения.
5. Откройте или обновите главную страницу YouTube.
6. Отметьте сначала одно видео и нажмите «Не интересует» на панели внизу страницы.

Временное дополнение удаляется после перезапуска Firefox. Для повторной проверки загрузите `manifest.json` ещё раз.

[Документация Mozilla о временной установке](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/).

## Проверка в браузере

1. Проверьте появление флажков возле обычных видео на главной странице.
2. Отметьте одно ненужное видео и выполните действие. Проверьте штатную реакцию YouTube на «Не интересует».
3. Повторите для двух видео и проверьте последовательную обработку.
4. Проверьте «Снять выбор», кнопку «Остановить» и переход с главной страницы на страницу видео.
5. Если меню не найдено или YouTube не отвечает, обработка остановится с сообщением. Проверьте результат для уже обработанных роликов и закройте открытое меню перед повторным запуском.

Пока идёт обработка, не открывайте другие меню и не переключайте страницы вручную, кроме проверки остановки.

## Постоянная установка

Для обычного Firefox нужна подпись Mozilla. Этот репозиторий содержит исходники неподписанного прототипа. Публикация на GitHub сама по себе не подписывает расширение.

После проверки работы можно подготовить пакет и отправить его на подпись Mozilla для самостоятельного распространения, без размещения в публичном каталоге дополнений.

[Подпись и распространение расширений](https://extensionworkshop.com/documentation/publish/signing-and-distribution-overview/).

## Данные и доступ

Скрипт загружается только на `https://www.youtube.com/*`, чтобы учитывать переходы внутри сайта без перезагрузки. Элементы выбора показываются только на главной странице.

Расширение не содержит аналитики, собственного сервера, хранилища или прямых сетевых запросов. Выбор хранится в памяти страницы. Нажатие «Не интересует» выполняется через интерфейс YouTube, который обрабатывает действие в вашей текущей сессии.

## Файлы

- `manifest.json` — описание расширения Firefox.
- `content.js` — выбор роликов и выполнение действий через меню YouTube.
- `style.css` — оформление флажков и панели.

Зависимости и сборка не требуются.
